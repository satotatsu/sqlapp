# Live demos

These are actual artifacts regenerated by sqlapp during the Pages build, using the
checked-in fictional customer/order Schema XML and two private in-memory HSQLDB databases.
No external database or credentials are used. All generated pages retain their own relative assets.

| Explore | Actual output |
|---|---|
| Three workflows together | [Generated overview](/sqlapp/demos/demo/index.html) |
| Database reference | [HTML tables, columns, constraints, indexes and DDL](/sqlapp/demos/offline-demo/index.html) |
| Relationships | [Clickable ER diagram](/sqlapp/demos/offline-demo/relationships.html) |
| Schema change | [Before](/sqlapp/demos/offline-change/before/index.html), [after](/sqlapp/demos/offline-change/after/index.html), [generated change SQL](/sqlapp/demos/offline-change/change.sql) |

| Schema XML | [Source model](/sqlapp/demos/catalog.xml) |

| Larger saved example | [20-table business reference](/sqlapp/docs/examples/gradle-html/index.html) |

The change SQL is generated for review and is **not executed**. Migration transfers
five fictional rows across two tables. Changing a target customer name then produces
a deliberate hash mismatch even though row counts match. No repair is performed.
This demonstrates HSQLDB-to-HSQLDB transfer, not a verified cross-vendor migration.

The 20-table reference is an existing checked-in output; unlike the customer/order
artifacts it is not regenerated by the site workflow.

Reproduce these outputs with Java 25 and the repository Gradle Wrapper:

```shell
./gradlew --init-script docs/examples/offline-html/demo.init.gradle demoSqlapp
```

On Windows use `.\gradlew.bat`. See the [guided tour](docs/getting-started/demo-tour.md)
for interpretation and [test-data generation](docs/data/test-data-generation.md)
and [DuckDB SQL models](docs/gradle-plugin/migration-models.md) for additional workflows.
The DuckDB example runs two dependency-ordered SQL models and one model unit test
on an isolated embedded connection. The resulting customer totals are asserted
before exporting the CSV. The JSON is a concise demo summary derived from command
results, not the bulk-migration verification report format.
No generated Data Generator run is included in this gallery yet.

```shell
./gradlew --init-script site/demo.init.gradle demoSiteDataEngineering
```
