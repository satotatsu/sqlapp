# はじめに {#getting-started}

[ドキュメント一覧](../README.md)

sqlappの使い方に合わせて入口を選んでください。

用途を検討している場合は、[ワークフローと出力例](use-cases.md)からはじめます。
データベースドキュメント、スキーマ変更の確認、検証付きデータ移行、階層型の業務処理を紹介しています。

| 目的 | ガイド |
|---|---|
| 大きな業務スキーマの生成結果を見る | [Gradle HTMLサンプル](gradle-html-example.md) |
| ドキュメント・変更確認・移行をまとめて試す | [デモツアー](demo-tour.md) |
| DBなしでHTML・ER図・テーブルDDLを見る | [顧客・注文のオフラインデモ](offline-demo.md) |
| SQLを適用せずスキーマ変更を確認する | [変更確認デモ](offline-demo.md#review-a-schema-change) |
| DBサーバーなしで転送と不一致検出を試す | [インメモリ移行デモ](offline-migration.md) |
| Excelテンプレートからリレーショナルなテストデータを生成する | [テストデータ生成](../data/test-data-generation.md) |
| Gradleビルドにタスクを追加する | [Gradle Plugin入門](../gradle-plugin/getting-started.md) |
| JavaでSchemaモデルを構築しSQLを生成する | [Java API](java-api.md) |
| Mavenで依存関係を宣言する | [Mavenの設定](maven.md) |
| Javaアプリケーションにコマンドを組み込む | [Command API](command-api.md) |

依存関係の選び方は[配布成果物](../artifacts.md)、バージョン境界と検証の根拠は[互換性](../compatibility.md)を参照してください。
